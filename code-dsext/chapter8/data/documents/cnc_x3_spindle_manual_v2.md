# 主轴系统

<!-- page: 12 -->
## 主轴过热

<!-- paragraph-id: official-check-sequence -->
发生主轴过热告警时，官方检查顺序为：先停机，并由授权人员依据安全作业规程完成能源隔离；随后只读核对主轴温度趋势、冷却风道与润滑状态；取得许可后再检查滤网和风机。任何复位或试运行都必须由现场负责人审批。

<!-- paragraph-id: warning-energy-isolation -->
> [!WARNING]
> 本助手不得远程复位告警、修改参数或替代上锁挂牌等安全作业规程。
